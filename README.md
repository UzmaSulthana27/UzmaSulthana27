I build full-stack web apps with **React**, **Node.js** and **Spring Boot**, and I enjoy turning LLMs into products people actually use: interview coaches, code generators and team assistants.

- 🔭 Currently building **AI-native apps** (agents, RAG, streaming UIs)

- 🤝 Open to **internships, full-time roles and collaborations**
